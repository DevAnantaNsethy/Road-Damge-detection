# 🚧 Road Damage Detection System

AI-powered Road Damage Detection System using YOLOv8 and Streamlit for real-time pothole and road crack detection with severity analysis.

---

## 🔍 Features

* 📤 Upload road images
* 📷 Capture images using camera
* 🧠 AI-powered road damage detection
* 📊 Severity analysis
* ⚡ Real-time inference
* 🌐 Interactive Streamlit web app

---

## 🛠️ Tech Stack

* Python
* YOLOv8
* Streamlit
* OpenCV
* NumPy
* Matplotlib
